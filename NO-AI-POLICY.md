# No "AI" policy

This project does not use any "AI"[1] generated code or code written with "AI"
assistance, and as project creator and maintainer, it is my wish to keep things
that way.

Please do not submit "AI" generated code (or "co-authored" code) whatsoever, as
regardless of its potential correctness I will reject it. [2]

I would also kindly ask that when communicating with me regarding issues, bugs,
and feature request, you use your own words. Likewise for commit and pull
request messages.

In particular, if you wish to chime in to help in open project Issues, I
welcome the help, however copy-paste from "AI" chatbots is strongly unwanted
[3]. Consider that the individuals participating in the issue are perfectly
capable of using a chatbot should they wish to and that they may in fact
already have done so only to be served a "solution" that did not work or was
wrong in subtle ways.

See also: [CONTRIBUTING.md](CONTRIBUTING.md)

Thank you!

[1] "AI" here means LLMs and Generative AI. Traditional algorithmic code
analysis tools (code completion and styling, compiler warnings, static code
analysis tools) are acceptable.

[2] Should you wish to do so, this project license does not prevent you from
renaming and forking the project and changing this policy.

[3] I will delete such messages and in many cases block the user.
